# Praktikum Algoritma dan Pemrograman Komputer 1 2026

**Notes!** <br>
Repository ini digunakan untuk mengumpulkan laporan praktikum, source code, serta kode percobaan

### Ketentuan 
1. Setiap praktikan diwajibkan untuk mengumpulkan penugasan (laporan praktikum dan source code) sesuai dengan tenggat dan format yang telah ditentukan
2. Setiap praktikan diwajibkan untuk mengumpulkan kode percobaan di laboratorium
3. Setiap praktikan diwajibkan untuk mengumpulkan setiap file pada folder yang sesuai
4. Format nama file percobaan : "Percobaan[x]_Pertemuan[y]}
5. Format nama file source code : "Tugas[x]_Pertemuan[y]"

### Hal yang perlu dikumpulkan
1. Laporan praktikum
2. Source code yang digunakan untuk mengerjakan laporan praktikum
3. Kode percobaan ketika di laboratorium

### Cara Mengumpulkan Kode Percobaan Dari Praktikum
1. Pada saat praktikum, ikuti materi dan buat kode percobaan sesuai dengan instruksi menggunakan NetBeans
2. Klik ctrl + a untuk memilih seluruh kode dan klik ctrl + c untuk melakukan copy terhadap kode tersebut
   <img width="1616" height="630" alt="image" src="https://github.com/user-attachments/assets/dae5c31e-faee-499e-9711-dd801ee32acd" />
3. Buka aplikasi NotePad++ dan klik "File", serta klik "New"
   <img width="1369" height="448" alt="image" src="https://github.com/user-attachments/assets/e5f3152a-b673-4015-b825-ea52013c460f" />
4. Klik ctrl + v untuk melakukan paste kode yang telah disalin sebelumnya
   <img width="1714" height="713" alt="image" src="https://github.com/user-attachments/assets/e8676100-cd5f-419e-8c9b-96031585f6f1" />
5. Agar kode tersebut berwarna dan dapat disimpan dengan format (.java), klik "File" lalu klik "Save As"
   <img width="1193" height="397" alt="image" src="https://github.com/user-attachments/assets/0e2bbcf5-c058-4a28-a85d-187696d99e8f" />
6. Ubah nama file tersebut sesuai format, yakni [Percobaan[x]_Pertemuan[y]]. Selanjutnya, klik "Save as type" dan cari "Java source file (*.java)". Selanjutnya, klik "Save"
   <img width="939" height="538" alt="image" src="https://github.com/user-attachments/assets/ab9d406f-4eaf-43e3-8089-d974461a50f9" />
7. Setelah dilakukan penyimpanan dengan format (*.java), maka tampila kode pada NotePad++ akan menjadi berwarna atau ter-highlight
   <img width="1580" height="698" alt="image" src="https://github.com/user-attachments/assets/5bf621d3-273d-4982-932b-4a6a9ba1308a" />
8. Masuk ke Repository milikmu dan klik salah satu folder pertemuan (sesuaikan dengan pertemuan di mana percobaan tersebut berlangsung).
   <img width="1668" height="517" alt="image" src="https://github.com/user-attachments/assets/d170ab5c-f33b-49a5-9dfd-853ad30e5d2c" />
9. Untuk mengunggah file kode percobaan, klik "Percobaan"
